# Spire Codex artwork

The WebP files in this directory were downloaded from the public Spire Codex
image service on 2026-08-11 for use by the Rusty Spire combat interface.

- Source API and attribution: https://spire-codex.com/developers
- Game-data version: stable v0.107.1
- Card renders: `https://cdn.spire-codex.com/cards-full/stable/<card>.webp`
- Character, monster, and relic images: the `image_url` returned by the
  corresponding Spire Codex entity endpoint.

These files are game artwork. They are kept separate from the application's
original source code and retain their original WebP encoding.
